第一步：多模态解构 (Decomposition)

利用 **Marker** 或 **Nougat** 将 PDF 全文转为 Markdown。

- **操作：** 自动将文档切分为：纯文本块、表格块（LaTeX格式）、图像块（自动编号保存）。
- **目的：** 消除PDF排版干扰，建立“图表编号-正文描述”的映射关系。

第二步：视觉数据数字化 (Visual-to-Data)

针对提取出的图片，先通过 LLM 判断图片类型（是否为等温线或穿透曲线）。

- **方案 A (高精度):** 使用 **YOLO** 检测坐标轴，利用图像处理算法（轮廓检测）提取曲线点。
- **方案 B (智能化):** 使用多模态模型（如 **DeepSeek-VL** 或 **GPT-4o-mini**）识别坐标轴数值和图例，直接估算关键数据点。

第三步：结构化信息抽取 (Structured Extraction)

将第一步生成的 Markdown 文本输入给 LLM（推荐使用带有推理能力的模型，如 DeepSeek-R1 或 GPT-4o）。

- **Prompt设计：** > “请从以下文本中提取 MOF 的名称、BET 比表面积、孔径（标注方法如DFT/BJH）、孔容。如果提到多个 MOF，请分别列出。单位统一输出为 XXX。”
- **约束：** 使用 **JSON Schema** 强制要求输出格式，便于后续直接转为 Excel。

第四步：冲突消解与单位归一化 (Normalization)

使用 Python 脚本进行后处理。

- **单位统一：** 利用 `Pint` 库或编写转换字典，将所有压力单位统一为 bar/kPa，容量统一为 mmol/g。
- **实体对齐：** 建立一个 MOF 别名表（如 MOF-5, IRMOF-1），利用模糊匹配（FuzzyWuzzy）或 LLM 进行同物异名合并。
